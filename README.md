# Property Social Hub

Crea un sistema y estategia completo de gestión de redes sociales (facebook, instagram, tiktok) para el mercadeo y captación de clientes de una empresa especializada en alquiler y venta de propiedades inmobiliarias. 

El sistema debe implementar la divulgación de contenido diario. 

Tu como mi asistente debes automatizar la divulgación diaria de contenido el cual tú mismo lo vas a generar. 

El sistema debe tener un menú lateral fijo con dos páginas: Dashboard con toda la información y estadísticas apropiadas y Colaboradores. 

Posteriormente debes enlazarte con todas las redes sociales para que puedas automatizar las tareas de publicación diaria. 

Adicionalmente debes realizar en manejo de las solicitudes y mensajeria, atenderlas y darles seguimiento. 

Por último, debes generar diariamente el informe de trabajo realizado
